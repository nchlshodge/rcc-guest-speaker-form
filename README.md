# RCC Guest Speaker Form

The guest speaker form for Rochester Christian Church, at https://guestspeaker.rochesterchristian.church.

A static page (GitHub Pages). Submissions go to a Google Apps Script web app ("RCC Guest Speaker Form" in the church Google account). The script saves each response to the "Guest Speaker Form Responses" Sheet and emails the church staff and the speaker. The script's code is kept out of this public repo.
